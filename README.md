# 💧 Water Refilling Station Management System

Welcome to the **Water Refilling Station Management System**! This is a simple, modern, and easy-to-use web application designed to help you run your water refilling business smoothly. 🚀

---

## ✨ Key Features

Here's what you can do with this system:

*   **📊 Dashboard**: Get a quick look at your daily sales, active customers, and pending orders.
*   **👥 Customer Management**: Add, view, and manage your customer details easily.
*   **📝 Order Management**: Create new orders and track their status (Pending, Delivered, etc.).
*   **📦 Inventory Tracking**: Keep track of your water containers and products. Never run out of stock!
*   **💰 Payment Records**: Record payments and track balances.
*   **📈 Reports**: Generate simple reports to see how your business is growing.
*   **🛡️ Secure Backup**: Keep your data safe with the built-in backup feature.

## 🚀 How to Install

Follow these simple steps to get started:

1.  **📥 Download**: Clone this repository or download the ZIP file.
2.  **📂 Extract**: Place the folder in your server directory (e.g., `C:\wamp64\www\` for WAMP).
3.  **🗄️ Database**:
    *   Open **phpMyAdmin**.
    *   Create a database named `water_refilling_db`.
    *   Import the `water_refilling_db.sql` file included in this project.
4.  **⚙️ Config** (Optional):
    *   Check `backend/config/db.php` if you need to change database settings.
5.  **🌐 Run**: Open your browser and go to `http://localhost/Water-Refilling-Station-Management-System`.
